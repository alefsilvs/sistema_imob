## 📋 Sobre o Sistema

O **ImobilPro** é um sistema completo de gestão imobiliária desenvolvido em Django, oferecendo:

### 🏠 Funcionalidades Principais

- **Gestão de Imóveis**: Cadastro e controle completo de propriedades
- **Contratos**: Gerenciamento de contratos de locação e venda
- **Financeiro**: Controle de pagamentos, IPTU, seguros e repasses
- **Manutenção**: Ordens de serviço e acompanhamento
- **Relatórios**: Dashboards e relatórios financeiros
- **Notificações**: Sistema de alertas via WhatsApp e email
- **NFe**: Emissão automática de notas fiscais

### 🛠️ Tecnologias Utilizadas

- **Backend**: Django 4.x + Python
- **Frontend**: Bootstrap 5 + JavaScript
- **Banco de Dados**: SQLite (configurável para PostgreSQL/MySQL)
- **APIs**: WhatsApp (Evolution API), NFe (Focus/Webmania)
- **Autenticação**: Sistema Django Auth
